# Gena

Локальный open-source сервис управленческого учёта для продавца Ozon по схеме FBO. Он объединяет каталог товаров, закупки, остатки, поставки, продажи, возвраты, расходы и расчёты в одном приложении с понятной расшифровкой итогов.

Сервис рассчитан на одного пользователя и один кабинет Ozon. Он запускается на компьютере владельца в контейнерах, хранит базу и резервные копии локально и обращается к Ozon только для получения предусмотренных данными API сведений. Доступ к сайту из внешней сети не требуется.

Это управленческий учёт, а не замена бухгалтерской или налоговой отчётности. Расчётный денежный баланс показывает внесённые расходы и учтённые операции Ozon до фактической выплаты; он не является банковским остатком.

## Правила, на которых строится сервис

- Товары можно вести в универсальном каталоге с внутренними артикулами и идентификаторами Ozon.
- В остаток и среднюю закупочную себестоимость входит только фактически полученный товар. Внесённая стоимость закупки уменьшает расчётный денежный баланс сразу.
- Сервис отдельно считает склад продавца и склад Ozon. Ручная поставка сразу перемещает товар между ними; удаление поставки убирает её эффект.
- Заказ уменьшает остаток Ozon после передачи покупателю. Статус Ozon «Доставлен» означает эту передачу; когда отдельная временная отметка недоступна, сервис сохраняет момент, когда впервые увидел этот статус. Обычные доставки младше 21 дня показываются отдельно. Выкуп маркетплейсом учитывается по финансовому отчёту Ozon.
- Возврат на склад Ozon возвращает товар в остаток, когда он снова доступен к продаже. Возврат продавцу попадает на его склад только после фактического получения.
- Денежный баланс, прибыль, себестоимость и остатки выводятся из исходных операций. Они не хранятся в виде самостоятельных итоговых чисел.
- Повторная синхронизация не должна создавать дубликаты. Для денежного баланса и прибыли доступна расшифровка по исходным операциям.

## Запуск на компьютере

Нужен Docker Desktop или Docker Engine с поддержкой Compose. В корне проекта выполните:

```sh
npm run start:local
```

При первом запуске создаются локальные пароли и ключ шифрования в файле `.env`, база данных и каталог резервных копий. Откройте адрес `http://localhost:3000`. Если порт занят, укажите свободный `APP_PORT` в `.env` и запустите сервис снова.

Чтобы остановить контейнеры, не удаляя данные:

```sh
npm run stop:local
```

База хранится в `data/postgres`. Ежедневные копии находятся в `data/backups`: архив базы, ключ шифрования API-ключа Ozon и параметры для переноса на другой компьютер. Хранятся 30 последних копий. Каталог резервных копий содержит секреты; не публикуйте его и не добавляйте в Git.

Чтобы заменить базу копией за выбранную дату, выполните:

```sh
npm run restore:local -- YYYY-MM-DD
```

Перед восстановлением сервис проверит целостность архива и попросит ввести подтверждение с выбранной датой. Для восстановления создаётся новая база с параметрами из копии; при сбое скрипт пытается вернуть прежнюю базу и настройки.

## Перенос истории

На странице импорта можно загрузить `.xlsx` или `.csv` и посмотреть предварительный результат без сохранения операций. После проверки можно применить перенос. Неопознанные или неполные строки попадут в отчёт; сервис не подставляет текущую дату вместо отсутствующей даты операции. Повторный импорт одинаковых строк не создаёт операции повторно, а исправленные или неполные версии с уже перенесёнными строками блокируются для сверки.

Предварительный прогон доступной выгрузки выполнен, но история не перенесена: строки с недостающими датами или неоднозначным сопоставлением нужно разобрать перед применением. Перед первым переносом загрузи актуальный экспорт и сверь отчёт с исходными данными.

## Состояние интеграции с Ozon

Сайт и база работают локально; веб-контейнер опубликован только на loopback-интерфейсе. Client ID и API-ключ вводятся в настройках и хранятся в базе в зашифрованном виде. Фоновый контейнер запускает синхронизацию по расписанию и ежедневные резервные копии. Запросы к кабинету владельца не выполнялись, так как учётные данные пока не введены.
